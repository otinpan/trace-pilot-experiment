# ウロボロス蛇シミュレーション問題 要件定義書

## 1. 概要

高橋くんが飼っている蛇「ウロボロス」を操作し、盤面上に散らばった餌を食べさせながら、最終的な蛇の体色列を目標の色列にできるだけ近づける問題である。

プレイヤーは各ターンごとに蛇の移動方向を指示する。

蛇は以下の特徴を持つ。

- 餌を食べると体が伸びる
- 伸びた部分は餌の色になる
- 自分の身体を噛みちぎれる
- 噛みちぎられた部分は餌として盤面上に残る

目的は以下の 2 点である。

1. 最終的な蛇の色列を目標色列へ近づける
2. 操作回数を最小化する

---

# 2. 用語定義

| 用語 | 説明 |
|---|---|
| 盤面 | `N × N` のグリッド |
| 蛇 | 頭から尻尾までの座標列と色列を持つオブジェクト |
| 餌 | 盤面上に存在する色付きアイテム |
| 色列 | 蛇の各部位に対応する色の並び |
| 目標色列 | 最終的に目指す理想の色列 |
| ターン | 1 回の移動操作 |

---

# 3. システム仕様

## 3.1 盤面仕様

- サイズは `N × N`
- 座標は `(0,0)` を左上とする
- 下方向に `i`
- 右方向に `j`

座標範囲:

```text
0 <= i < N
0 <= j < N
```

制約:

| パラメータ | 範囲 |
|---|---|
| N | 8 ～ 16 |
| C | 3 ～ 7 |

---

# 4. 蛇仕様

## 4.1 蛇の構造

長さ `k` の蛇は以下を持つ。

### 座標列

```text
(i0,j0), (i1,j1), ..., (ik-1,jk-1)
```

### 色列

```text
c0, c1, ..., ck-1
```

---

## 4.2 部位定義

| インデックス | 部位 |
|---|---|
| 0 | 頭 |
| 1 ～ k-2 | 胴体 |
| k-1 | 尻尾 |

---

## 4.3 初期状態

初期蛇:

| 順番 | 座標 | 色 |
|---|---|---|
| 0 | (4,0) | 1 |
| 1 | (3,0) | 1 |
| 2 | (2,0) | 1 |
| 3 | (1,0) | 1 |
| 4 | (0,0) | 1 |

初期長さ:

```text
5
```

---

# 5. 餌仕様

## 5.1 餌の属性

各餌は以下を持つ。

| 属性 | 内容 |
|---|---|
| 位置 | `(i,j)` |
| 色 | `1 ～ C` |

---

## 5.2 餌数

盤面上には:

```text
M - 5
```

個の餌が存在する。

---

# 6. ターン処理仕様

1 ターンで以下を順番に処理する。

---

## 6.1 移動処理

プレイヤーは方向 `d` を指定する。

```text
U D L R
```

### 移動後

新しい頭:

```text
(i0', j0')
```

新しい蛇:

```text
(i0',j0'),
(i0,j0),
(i1,j1),
...
(i(k-2),j(k-2))
```

---

## 6.2 禁止移動

以下は禁止。

### Uターン

```text
(i0',j0') == (i1,j1)
```

### 盤面外

```text
0 <= i < N
0 <= j < N
```

を満たさない移動。

---

## 6.3 食事処理

移動先に餌が存在する場合:

- 蛇の長さ +1
- 尻尾が伸びる
- 新しい末尾色 = 餌色

### 色列更新

```text
c0,c1,...,ck-1,c'
```

---

## 6.4 噛みちぎり処理

移動後に:

```text
head == body
```

となる場合発生。

### 条件

```text
1 <= h <= k-2
```

### 処理内容

蛇長:

```text
h + 1
```

に短縮。

切断された部分は餌になる。

---

# 7. 入力仕様

## 7.1 入力形式

```text
N M C
d0 ... d(M-1)
f00 ... f0(N-1)
...
f(N-1)0 ... f(N-1)(N-1)
```

---

## 7.2 目標色列

```text
d0 ... d(M-1)
```

### 条件

```text
d0 = d1 = d2 = d3 = d4 = 1
```

---

## 7.3 盤面情報

```text
f(i,j)
```

| 値 | 意味 |
|---|---|
| 0 | 餌なし |
| 1～C | 色付き餌 |

---

# 8. 出力仕様

## 8.1 出力形式

各行に移動方向を出力。

```text
U
D
L
R
```

---

## 8.2 操作回数

```text
T <= 100000
```

---

# 9. スコア仕様

## 9.1 定義

| 記号 | 意味 |
|---|---|
| T | 操作回数 |
| k | 最終蛇長 |
| E | 色不一致数 |

---

## 9.2 色誤差

```text
cp != dp
```

となる数。

---

## 9.3 スコア式

```text
Score = T + 10000 × (E + 2(M-k))
```

小さいほど高評価。

| C | 3 ～ 7 |

# 11. システム目的

本システムは以下を目的とする。

- 効率的な蛇移動戦略の探索
- 色列最適化
- 自己切断を利用した状態制御
- 操作回数最小化

# 12. 想定されるアルゴリズム

## 12.1 基本戦略

- BFS
- DFS
- 貪欲法
- Beam Search
- 焼きなまし

---

## 12.2 重要な戦略

### 餌取得順最適化

目標色列に近づくよう取得。

### 自己切断活用

不要部分を切断。

### 経路最適化

移動コスト削減。
